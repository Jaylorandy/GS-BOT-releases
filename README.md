# GS Bot — Release Channel

本仓库**只存放 GS Bot 的发布产物**（Windows 安装包与自动更新元数据），不包含任何源码。

## 下载最新版

- 最新版本页：<https://github.com/Jaylorandy/GS-BOT-releases/releases/latest>
- 安装包文件名：`GS-Bot-Setup-<版本>.exe`

## 自动更新

客户端内置的自动更新读取本仓库 Release 中的 `latest.yml` 与对应安装包，
因此本仓库需要保持 **public**，否则已安装的客户端将无法检查更新。

> 请勿将源码或私钥提交到本仓库。
